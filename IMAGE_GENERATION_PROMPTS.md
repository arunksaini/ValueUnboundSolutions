## General Guidelines for All Images

1. **Professional Tone:** These are B2B enterprise software articles - avoid cartoon-like or overly casual styles
2. **Color Consistency:** Stick to the brand palette (blues #1e40af, greens #059669, purples #7c3aed)
3. **Salesforce Elements:** Subtly incorporate Salesforce branding (clouds, CRM dashboards) without trademark violations
4. **Business Context:** Include enterprise elements (dashboards, documents, corporate settings)
5. **Metaphors:** Use clear visual metaphors (traps, bloat, shadows, optimization)
6. **Resolution:** Request high-resolution outputs suitable for web (minimum 1920x1080)
7. **Aspect Ratio:** Always 16:9 landscape format for blog headers
8. **No Text:** Avoid text in images as it reduces reusability and internationalization

## How to Use These Prompts

### For Gemini/Imagen (Google AI Studio):
```bash
# Use the Imagen API with each prompt
curl -X POST \
  "https://aiplatform.googleapis.com/v1/projects/YOUR_PROJECT/locations/us-central1/publishers/google/models/imagegeneration:predict" \
  -H "Authorization: Bearer $(gcloud auth print-access-token)" \
  -H "Content-Type: application/json" \
  -d '{
    "instances": [{
      "prompt": "[PASTE PROMPT HERE]"
    }],
    "parameters": {
      "sampleCount": 1,
      "aspectRatio": "16:9"
    }
  }'
```

### For DALL-E 3 (ChatGPT):
1. Copy the prompt
2. Paste into ChatGPT with "Generate an image: [prompt]"
3. Request size: 1792x1024 (landscape)

### For Midjourney:
1. Copy the prompt
2. Add at the end: `--ar 16:9 --quality 2 --style raw`
3. Use in Discord: `/imagine prompt: [prompt] --ar 16:9 --quality 2`
